# 全局规范

## 命名规则

- 车间名称：中文 + "车间"后缀，如 `文本处理车间`
- 项目名称：简洁中文描述，如 `结构化重塑`、`摘要生成`
- 提示词文件：统一命名为 `prompt_v0.1.md`，版本递增改为 `v0.2`、`v1.0`
- 进化包文件夹：统一命名为 `_skill_evolution`
- 占位文件：空文件夹使用 `.gitkeep`

## 文件格式要求

- 所有文档使用 Markdown 格式
- 标题层级从 `#` 开始，不跳级
- 列表项保持统一缩进（2空格或4空格任选一种，全文一致）
- 代码块标注语言类型（如 ```markdown、```bash）

## 全局指令约定
根目录 _prompts/ 下存放所有跨车间共享的系统级 AI 操作指令（如更新 loader、全局迁移等），命名须带 _global_ 或明确作用域（例：rebuild_loader.md 专用于 loader 更新）。

## 变更管理

- 任何新增、修改、删除操作必须同步记录到 `_config/changelog.md`
- changelog 按时间倒序排列，最新条目在最上方
- 每条记录包含：日期、操作类型、涉及路径、简要说明

## 注意事项

- 不要直接覆盖已有的 prompt 文件，升级通过补充 `_skill_evolution/` 文档完成
- 新建项目前请先阅读本文件，确保结构符合规范
