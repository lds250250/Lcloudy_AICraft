# `_prompts/` 目录说明 · 全局编写器工作台

> 本目录存放用于**生成技能文件**的 AI 编写器（Writer）。单文件体系下只有一个编写器：`write_skill.md`，一次性生成完整的 `{技能名}_skill_vX.X.md`（四章合一，技能名作文件名前缀）。产出文风与「结构化重塑」技能保持统一。

---

## 📂 现有文件清单

| 文件名 | 用途 | 输入要求 |
| :--- | :--- | :--- |
| `write_skill.md` | 生成完整的单文件技能 `{技能名}_skill_vX.X.md` | 技能名称 + 一句话定位 + 提示词模板内容（全文） |

---

## 🔁 生成规则

- **一次调用，一份完整文件**：产出即含四章（📥 加载说明 / 🧭 工作指令 / ✅ 验收标准 / 📝 提示词模板），不再分步生成
- 提示词模板内容必须由用户提供全文，编写器不代写、不猜测
- 四章缺一不构成 skill（判定标准见 `_config/global_rules.md`）

---

## ⚠️ 使用注意事项

- **版本号**：首版为 `1.0`；升版时文件名与标题版本号同步更改（单文件无外部引用，改名零成本）
- **验收机制**：红线二元核验 + 双向追溯 + 风险披露，不引入任何定量打分；批评者二审仅高风险场景启用
- **prompt 阶段的过渡**：技能在 prompt 阶段保留独立的 `{技能名}_prompt_vX.X.md`；用本编写器升级成 `{技能名}_skill_vX.X.md` 后，原 prompt 文件并入并删除，同一技能同一时间只保留一个活跃文件

---

## 📌 快速调用示例（对话模板）

> “请用 `write_skill.md` 的规则，为「[新技能名称]」生成技能文件。定位：[一句话描述]。提示词模板内容如下：[粘贴全文]”
