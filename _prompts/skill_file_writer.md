# 技能文件编写器（Skill File Writer）

> 本提示词用于指导 AI 或人类，按统一文风和结构生成 `spec.md`、`eval.md`、`examples.md`、`skill_loader.md` 四份技能文件。所有输出必须与「结构化重塑」技能的现有文件保持风格一致。

---

## 📁 适用场景

当你在任意 `[车间]/[项目]/_skill_evolution/` 目录下需要创建或更新以下文件时使用：
- `spec.md` —— 技能说明书（定义原则、策略、输出规范）
- `eval.md` —— 质量验收标准（定量评分体系）
- `examples.md` —— 优秀案例集（附评分对照）
- `skill_loader.md` —— 技能加载器（执行入口）

---

## 🎨 统一文风规范（所有文件必须遵守）

| 要素 | 规范 |
| :--- | :--- |
| **人称** | 统一使用“AI”作为执行主体，不使用“你/我” |
| **语气词** | 统一使用“必须/应当/禁止”三类语气，避免“建议/尽量/最好”等模糊词 |
| **编号体系** | 顶层用数字（1. 2. 3.），子级用字母（a. b. c.）或缩进列表，图标仅作视觉辅助 |
| **版式头部** | 每个文件顶部必须包含：`> **版本**：vX.X \| **更新日期**：YYYY-MM-DD` |
| **注释/说明块** | 使用 `>` 引用块放置说明性文字（如文件用途、执行提示） |
| **优先级字段** | 若文件包含多条原则/规则，必须标注优先级（如 `优先级1`、`优先级2`） |
| **评分/检查项** | 涉及评估时，必须使用 1-5 分制评分表，并附带锚点描述 |
| **路径引用** | 相对路径使用 `./`（同级）或 `../`（上级），禁止硬编码绝对路径 |
| **分隔符** | 使用 `---` 分隔章节，使用 `##` 作为二级标题，`###` 作为三级标题 |
| **禁止语** | 不使用“首先、其次、最后、众所周知、非常重要”等空泛套话 |
