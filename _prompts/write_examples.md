# Examples 编写器

## 你的任务
根据用户提供的「技能名称」、该技能的 `spec.md` 和 `eval.md` 的**实际内容**，生成一份 `examples.md` 文件。**文风、句式、标点必须严格遵循下方模板**。

---


---

## ⚠️ 填写要求（针对占位符）

| 占位符 | 填写规则 |
| :--- | :--- |
| `[技能名称]` | 用户提供的技能名称 |
| `[案例名称]` | 用该技能真实处理过的一类典型文本命名 |
| `[内容类型]` | 对应 `spec.md` 结构策略表中的某一类型（如“观点/评论类”） |
| `[要点1-4名称]` | 提炼该案例中“最能体现技能价值”的4个输出特征 |
| `[eval中的维度名称]` | **必须完全复制 `eval.md` 中的维度名称原文**，确保编号对应 |
| `[评语]` | 用一句话说明“为什么得这个分”，不重复锚点描述（如“结论先行且支撑扎实”而非“符合5分标准”） |

---

## 🚫 禁止行为
- 不省略验收评分表。
- 不改变评分表的列数或表头。
- 不虚构案例（应基于真实场景）。
