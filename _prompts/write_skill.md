## ✅ 验收标准

> 本章在输出定稿前做「核验 + 披露」：不打分、不自评表演。所有检查均为「是/否」可回答的二元判断，结论随输出附带。

### 红线核验（任一不通过即修正后重写）

| 编号 | 检查项 | 判定 |
| :---: | :--- | :--- |
| R1 | **[检查项1：必须是"零编造/零幻觉"类]** | 不通过 → 一票否决 |
| R2 | **[检查项2]** | 不通过 → 重写 |
| R3 | **[检查项3]** | 不通过 → 重写 |
| R4 | **[检查项4：格式合规类]** | 不通过 → 修正 |

（红线项 3-5 条，全部必须能用「是/否」回答；R1 固定为一票否决项）

> **一票否决**：R1 不通过时，无论其余结果如何，一律重写。

### 双向追溯（对照输入逐项进行）

- **正向查遗漏**：从输入提取关键点清单，逐一确认能在输出中找到。
- **反向查编造**：从输出提取所有事实性断言，逐一确认在输入中有出处。
- 无法确认的内容标注「[不确定标记，默认"待核实"]」，不擅自改写。

### 风险披露（强制，置于输出末尾）

输出以如下一句话收尾：

> **风险披露**：本次处理中最可能失真的一处是 ___（无则写"无"）；标注「[不确定标记]」的内容共 N 处。

### 批评者二审（可选，高风险场景启用）

切换「[二审角色，默认"挑剔的主编"]」角色对产出进行二审：只列违规点，不打分、不表扬。二审发现问题则修正后再输出。

- 不改变模板中的固定句式与表格表头。
