# 结构化重塑 · 评估标准 (eval.md)

> 本文档用于检验 AI 输出的结果是否合格。每次使用 prompt 后，可对照以下标准打分或检查。

## 🟢 通用基础标准（所有版本都必须满足）

- [ ] **无幻觉**：AI 没有编造原文中不存在的事实或数据。
- [ ] **无遗漏**：原文的核心观点、关键数据、重要结论全部被保留，没有丢失。
- [ ] **格式正确**：严格使用了 Markdown 语法（加粗、表格、列表、引用块等），在 GitHub 或笔记软件中能正常渲染。
- [ ] **语言精炼**：没有废话，删除了原文的冗余修饰词，阅读流畅。

---

## 🔷 版本一：全景重构版 评估标准

*适用场景：长篇大论、碎片化信息、需要深度整理的文章*

- [ ] **逻辑闭环**：是否按照「核心结论 → 关键论据 → 底层逻辑 → 行动建议」的顺序排列？
- [ ] **视觉分层**：
  - 核心观点是否用了 **加粗** 或 `> 引用块`？
  - 并列/对比信息是否转化成了表格？
  - 步骤是否用了有序列表（1. 2. 3.）？
- [ ] **体系升华**：文末是否包含「认知框架图」或「一页纸精华摘要」？
- [ ] **段落控制**：每段文字是否控制在 3 行以内？

---

## 📊 版本二：矩阵透视版 评估标准

*适用场景：数据对比、参数罗列、多维度分析*

- [ ] **核心摘要**：开头是否有一段 50 字以内的摘要？
- [ ] **表格体系**：
  - 主体内容是否拆分成了多个表格？
  - 每个表格是否有清晰的表头？
  - 表格内的关键数据/结论是否 **加粗**？
- [ ] **过渡自然**：表格之间是否有简短的过渡句串联？
- [ ] **关键 takeaway**：结尾是否列出了 3-5 条关键要点（bullet points）？

---

## 🧠 版本三：认知内化版 评估标准

*适用场景：复杂概念学习、理论梳理、读书笔记*

- [ ] **What**：是否用一句话清晰定义了核心概念？
- [ ] **Why**：是否用表格对比了「传统认知 vs 新认知」？
- [ ] **How**：是否用递进步骤拆解了方法论，并配有具体案例？
- [ ] **System**：是否绘制了文字版的「知识树」或「思维导图」结构？
- [ ] **Check**：文末是否提供了 2-3 个自测问题？
- [ ] **易读性**：排版是否留白充足、短句为主，看起来轻松不压抑？

---

## 📝 如何使用这份标准？

1. 把原始文本喂给 AI，拿到输出结果。
2. 根据您使用的版本（全景/矩阵/认知），勾选上面对应的 `[ ]`。
3. 如果某一项没打勾，说明 AI 这次表现不完美，您可以：
   - 追问 AI：“请补充文末的认知框架图”
   - 或者微调 prompt 后重试。
4. 完美的输出案例，可以复制到 `examples.md` 中作为正样本保存。
