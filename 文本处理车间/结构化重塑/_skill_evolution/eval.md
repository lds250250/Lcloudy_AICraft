# 结构化重塑 · 质量验收标准

> 这份文档用于在 AI 输出内容后，快速判断其是否达到"可直接发布/归档"的标准。

## ✅ 核心验收三原则

1. **零失真**：核心观点、历史事实、关键数据必须与原文一致，严禁 AI 自行发挥或编造细节。
2. **逻辑显性化**：原文隐含的逻辑关系（如因果、对比、递进）必须通过排版（标题、列表、表格）显性展示出来。
3. **阅读降噪**：去除口语化赘述、重复修辞，保留干货，确保读者能在 30 秒内抓住重点。

## 🔍 分项检查清单

### 1. 结构层级检查

| 检查项 | 评分（1-5） | 锚点描述 |
| :--- | :--- | :--- |
| 金字塔原理 | ___ | 1=平铺直叙无结论；3=结论先行但支撑松散；5=结论→论据→底层逻辑清晰递进 |
| 标题有效性 | ___ | 1=全是“第一部分/第二部分”；3=部分标题有概括性；5=每个标题都是该段核心 |
| 层级清晰度 | ___ | 1=全文只有1个大标题；3=有H2/H3但层级跳脱；5=层级规整，H2/H3递进合理 |

### 2. 内容完整性检查
- [ ] **关键点无遗漏**：原文提到的所有核心制度（如三省、二府、内阁）及其优缺点是否都涵盖了？
- [ ] **对比维度对齐**：如果原文在进行对比（如效率对比），AI 是否将所有对象在同一维度下进行了平行阐述？
- [ ] **引用准确**：原文中的专有名词（如"票拟"、"批红"、"政事堂"）是否保留且使用正确？

### 3. 可视化与排版检查
- [ ] **表格转化**：涉及多维度对比（如三种制度的优劣）时，是否自动转化为了 Markdown 表格？
- [ ] **重点突出**：关键结论、核心定义是否使用了 **加粗**？
- [ ] **列表化**：超过 3 点的并列内容，是否使用了无序列表或有序列表，而非长段落堆砌？

## 🚫 常见不合格案例（避坑指南）

| 问题类型 | 错误表现 | 修正要求 |
| :--- | :--- | :--- |
| **过度精简** | 丢失了原文的 nuanced（细微差别），把复杂的政治博弈简化为干巴巴的条目 | 保留关键修饰语和背景限定词 |
| **逻辑断层** | 只有罗列没有串联，看不出 A 制度是如何演变为 B 制度的 | 增加过渡句或小标题体现演变脉络 |
| **格式混乱** | 表格列宽不一致，或者列表缩进混乱 | 统一 Markdown 语法规范 |
| **幻觉风险** | 编造了原文没有提到的朝代或官职 | **必须回溯原文核实** |
