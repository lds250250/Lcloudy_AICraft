# 结构化重塑 · 质量验收标准（Eval）

> 本文件用于 AI 完成输出后，按定量评分体系快速判定是否达到“可直接发布/归档”的合格线。每项检查均采用 1–5 分制，总分 ≥ 18/25 视为通过。

---

## ✅ 核心验收三原则（定性纲领）

1. **零失真**：核心观点、历史事实、关键数据必须与原文一致。
2. **逻辑显性化**：隐含逻辑关系必须通过排版显性展示。
3. **阅读降噪**：去除口语赘述，确保 30 秒内抓住重点。

---

## 🔍 定量评分检查清单

| 编号 | 检查维度 | 评分（1–5） | 锚点描述 |
| :---: | :--- | :---: | :--- |
| **1.1** | **金字塔原理** | ___ | 1 = 平铺直叙，无结论先行；<br>3 = 有结论但支撑松散；<br>5 = 结论 → 论据 → 底层逻辑清晰递进 |
| **1.2** | **标题有效性** | ___ | 1 = 全是“第一部分/第二部分”类无效标题；<br>3 = 部分标题有概括性；<br>5 = 每个标题精准概括该段核心 |
| **1.3** | **层级清晰度** | ___ | 1 = 全文仅 1 个大标题；<br>3 = 有 H2/H3 但层级跳脱；<br>5 = 层级规整，H2/H3 递进合理 |
| **2.1** | **关键点无遗漏** | ___ | 1 = 丢失 ≥ 30% 核心信息；<br>3 = 丢失少量次要细节；<br>5 = 所有核心制度/观点/数据完整保留 |
| **2.2** | **对比维度对齐** | ___ | 1 = 对比对象维度不统一；<br>3 = 维度基本对齐但有偏差；<br>5 = 所有对象在同一维度下平行阐述 |
| **2.3** | **引用准确** | ___ | 1 = 专有名词错误或遗漏；<br>3 = 个别术语不准确；<br>5 = 所有专有名词保留且使用正确 |
| **3.1** | **表格转化** | ___ | 1 = 多维对比仍用段落堆砌；<br>3 = 部分使用表格但格式不规范；<br>5 = 所有对比都转化为规范 Markdown 表格 |
| **3.2** | **重点突出** | ___ | 1 = 无任何加粗或强调；<br>3 = 部分关键点加粗；<br>5 = 所有核心结论/术语均加粗 |
| **3.3** | **列表化** | ___ | 1 = 超过 3 项的并列仍用长段落；<br>3 = 部分列表化但缩进混乱；<br>5 = 所有并列项用规范列表呈现 |
| **4.1** | **避坑检查（反向扣分项）** | 扣分（0–5） | 出现“过度精简”扣 1 分；<br>出现“逻辑断层”扣 2 分；<br>出现“格式混乱”扣 1 分；<br>出现“幻觉风险”扣 5 分（一票否决） |

---

## 📊 评分汇总与判定

| 总评分计算公式 | 通过标准 |
| :--- | :--- |
| **总分 = (1.1+1.2+1.3+2.1+2.2+2.3+3.1+3.2+3.3) – 4.1扣分** | **≥ 18** → 通过（可发布/归档）<br>**＜ 18** → 退回修改 |

> **一票否决**：若 4.1 项“幻觉风险”扣分为 5（即出现编造事实），无论总分多少，直接判定为 **不合格**。
