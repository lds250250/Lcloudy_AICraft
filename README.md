# Lcloudy_AICraft

> 从提示词到技能，让 AI 能力真正落地

AICraft 是一个为 AI 实践者设计的**能力演进工作区**。它不只是存储提示词的仓库，更是将零散指令打磨为标准化技能的工坊。在这里，每一个 Prompt 都是 Skill 的起点，每一次迭代都让 AI 能力更接近生产级标准。

## 🎯 核心定位

- **统一承载**：同时管理提示词（Prompt）与技能（Skill），避免资产分散
- **演进驱动**：内置 `_skill_evolution/` 进化包机制，明确提示词升级为 Skill 的路径
- **场景导向**：按业务场景（而非技术类型）组织内容，贴近实际使用习惯
- **极简命名**：顶层英文简洁标识，子级中文直白分类，零认知负担

## 📂 目录结构

```text
AICraft/
